<p align="center">
  WebBuddy is an ultra-fast, privacy-first desktop web browser featuring real-time ad and tracker blocking, multi-engine search orchestration, auto picture-in-picture media controls, and a productivity suite.
</p>

---

## ✨ Features

- 🛡️ **WebBuddy Shields**: Real-time ad and tracker blocker with sub-millisecond filtering and privacy metrics (EasyList, EasyPrivacy, uBlock, Anti-Fingerprinting).
- 🔍 **Multi-Engine Search**: Switch seamlessly between Google, DuckDuckGo, Brave, Bing, Ecosia, Yahoo, or add custom search engines with keyword shortcuts.
- 🎬 **Smart Media Hub & Auto-PiP**: Picture-in-Picture overlay with floating player, playback speed boosters, and video controls.
- 📝 **Productivity Notes Sidebar**: Quick markdown notepad with URL clipping, color badges, and persistent local storage.
- 🎨 **Futuristic NTP (New Tab Page)**: Curated high-res dynamic wallpapers, live privacy telemetry, clock widgets, and customizable speed dial.
- ⚡ **Lightweight & Modular**: High performance architecture powered by Vite and Electron.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/anshulyadav32/webbuddy-browser.git

# Navigate to project directory
cd webbuddy-browser

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev

# Launch Electron desktop application
npm run app
```
